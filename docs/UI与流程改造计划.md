# 摸金地图工具：UI 与流程改造计划（Phase 7+）

> 起草：2026-09-10，基于用户游戏内实跑反馈。
> 前置：重构 Phase 0-5 + 阶段1-3（热键/状态/样本预览/设置面板）已完成（commit 至 e935830 + _show_centered fix pending）。
> 本文是「先整理到文档再行动」的产物，未批准不动代码。

## 一、背景：实跑暴露的问题

1. **`_show_centered` 崩溃**（已修，commit 待入）：`_screen_size()` 返回 `(宽,高)`，`_show_centered` 写 `h,w=...` 把宽高赋反；屏幕高<874（非1920×1080 或 DPI 缩放）时切出宽 0 → 广播错。已修顺序+兜底。
2. **右侧工具列污染样本**：游戏内打开地图后，地图右侧固定有一列工具按钮/图标。自动裁入口样本（`_crop_around_icon` 以图标为中心裁方框）或手动框选时，若把右侧工具列包进去，会干扰匹配/对齐。**后续裁样本须排除右侧工具列区域**。
3. **手动框选未生效**：用户手框样本后，软件没按框选范围匹配（`_manual_sample_pick` 流程没接通或 `sample_crop` 没传对）。
4. **手动选种子未接入**：用户手动选方向+门（北-沙发门）后，软件没按选定种子继续重合流程（`_realign` 存在但没和"接入自动"按钮串好）。
5. **三点标定黑屏**：`ClickPicker` point 模式标第一个点后窗口直接黑，不能继续标第 2/3 点。**疑似根因**：`QLabel` 同时 `setPixmap`（显示图）和 `setText`（标点进度）互斥——`setText` 会清掉 pixmap → 黑屏。
6. **分辨率局限**：`FIXED_PANEL(668,166,1064,569)` 硬编码 1920×1080，部署到其他分辨率电脑无效。需多分辨率适配。

## 二、改造目标

- **流程主线 = 一键全自动**（热键 或 「一键匹配」按钮）：截屏→入口匹配→两段式对齐→投影重合，全程自动。
- **任意一步出问题可手动介入，介入后按「接入自动」按钮回到自动流程贯通到投影**：
  - 入口样本不对 → 手框样本 →【尝试匹配】→ 自动剩余流程
  - 匹配种子不对 → 手动选方向+门 →【按此对齐】→ 自动剩余流程
  - 对齐不对 → 手动选点(3点标定) →【按此对齐】→ 自动剩余流程
- **UI 精简**：主界面只留高频按钮；低频（素材管理/标记出错/设置/查看日志/热键状态）折叠进「选项」。
- **样本选取**：自动裁样本排除右侧工具列；手动框选正确接入匹配。
- **多分辨率**：动态检测迷雾面板位置，可部署到其他分辨率/DPI 电脑。

## 四、分阶段任务

### 阶段 A：修当前确定 bug（小，先做，不改架构）
- **A1 手动框选生效**：`_manual_sample_pick` 调通——框选 rect → `sample_crop` → `find_seed_by_entrance(sample_crop=)` → `_after_match`。验收：手框真实入口区域→出种子→投影。
- **A2 三点标定不黑屏**：`ClickPicker` point 模式标点不清图。根因 `QLabel.setPixmap`+`setText` 互斥。修：点标注用 `paintEvent` 画在 pixmap 上，或用独立 overlay 层画点不碰 pixmap。验收：连点 3 点不黑屏、出仿射变换投影。
- **A3 手动选种子接入自动**：「按选定种子对齐」按钮 → 复用 `_realign`（当前方向+门+楼层全搜对齐）→ 投影。验收：选方向+门→按钮→投影重合。
- **A4 右侧工具列排除**：`_crop_around_icon` 裁样本时裁掉右侧 N 像素；或 `detect_fog_panel` 定位地图内容右边界后裁掉工具列。需测右侧工具列宽度（待用户提供或截图标注）。

### 阶段 B：UI 重构（按钮分组 + 流程接入）
- **B1 主界面高频按钮**：
  - 「一键匹配」（=热键效果，`_entrance_pipeline`）
  - 「✂ 手框样本」→ 框完 →「尝试匹配」（用手框样本走匹配+对齐+投影）
  - 方向/门/楼层下拉 +「按此对齐」（手动选种子走对齐+投影）
  - 「✋ 手动选点重合」→ 选 3 点 →「按此对齐」（仿射标定走投影）
- **B2 「选项」折叠按钮**：点开菜单/抽屉含 素材管理 / 标记上次错 / 设置 / 查看日志 / 热键状态。
- **B3 每个介入入口配「接入自动」按钮**：手动介入后→按钮→跑剩余自动流程（`_after_match` 或 `_two_stage_align`+投影）。
- **B4 状态灯+精简状态行留主界面**；完整日志进「选项→查看日志」或可折叠日志区。

## 五、UI 优化建议（可选，试做）
- 流程进度条/状态机可视化：当前步亮起（截屏→匹配→对齐→投影），一眼看到卡哪步。
- 热键提示：主界面常显当前热键串（如 `Ctrl+Shift+F`），点改键直进设置。
- 样本预览窗叠加框选：手框时预览窗实时显示框选区域 + 自动裁的对比。
- 失败回收一键化：投影不对时一个「这次错了」按钮直接归档进 `eval/inbox/`（现「标记上次错」）。
