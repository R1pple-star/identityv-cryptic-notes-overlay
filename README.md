# 加页手记 · 摸金地图叠层工具

第五人格「摸金」模式的地图叠层辅助工具：按下热键，自动识别当前对局种子，把参考地图以半透明投影精准叠合在游戏内小地图上，并在你平移/缩放地图时自动跟随。

> ⚠️ 本项目为个人学习用途的**非官方**工具，与网易第五人格官方无关。

## 功能

- **一键匹配**：热键（默认 `Ctrl+Shift+F`）→ 截屏 → 入口引索匹配（墙重合度量）确定种子 → 两段式对齐 → 透明投影重合到游戏内小地图。
- **自动跟随·开合**：游戏内 `G` 键开关小地图时，投影同步显隐；关掉再开回，投影自动放回原位。
- **自动跟随·平移/缩放**：拖动、缩放游戏内地图时投影自动跟上，无需再按热键（缩放滑条读数 + 图标尺子双尺度源）。
- **人工纠错**：主窗「🔄 换种子」（拉黑当前候选试下一个）、「🔀 换楼层」（一楼⇄二楼）、「按此种子重新对齐」、手动选点重合。
- **克制的不确定处理**：信息不足（刚进门重雾、探明度过低）时**拒答**而不是乱给一张图。

## 工作原理（一页版）

```
热键 → 截屏 → 地图画面闸 → 入口匹配 → 两段式对齐 → 投影
```

- **入口层 = 墙重合度量**：把截屏样本与 28 个种子的入口引索图各取墙掩膜，按锚定落点算双向覆盖率，分 = `1 − 覆盖率`。墙是细线，对位置敏感、对迷雾免疫。
- **对齐层 = 错配率**：把探明像素分类成 5 类做 one-hot，用互相关数「一致像素」的加权占比，而不是像素平方差（后者会被少数离群像素主导，见 `core/vision.py` 注释）。
- **双闸**：入口置信闸（种子 ID 可信）与对齐显示闸（投影该不该显示）量纲不同、各配各的阈值（`config.toml [match]`），都过才出图。
- 图标锚定（入口白箭头 ↔ 引索图标）钉死平移、只搜尺度，防迷宫网格自相似导致的「幽灵相位」。

## 环境要求

- Windows 10/11，游戏**全屏** 1920×1080（16:9 其它分辨率等比外推，未实测；非 16:9 需在 `config.toml [panel.rects]` 校准）。
- Python 3.11+（用到标准库 `tomllib`）。

## 安装

```bash
pip install -r requirements.txt
```

1. **准备参考图库**（工具不自带答案图，需自备）：摸金模式 28 个种子 × 2 楼层的参考地图。本项目的地图素材来自博主 **凉哈皮** 的摸金地图，请自行获取后放入一个目录。
   文件名格式：`{种子号} {方向}-{门特征}{楼层}.png`，如 `1 右-左上右下门一楼.png`（解析规则见 `core/map_library.py`）。
2. **配置路径**：编辑 `config.toml` 的 `[paths]`：
   - `map_library` = 你的参考图库目录
   - `shot_library` = 游戏截图存放目录（测试样本，可选）
3. **重建入口引索**（若你的参考图与仓库内置的不同）：
   ```bash
   python build_entrance_index.py
   ```
4. **重建导航列模板**（若游戏 UI 更新导致开合判断失效）：
   ```bash
   python build_ui_template.py <全屏实机截图1> <全屏实机截图2> ...
   ```

## 使用

```bash
python app.py
```

- 进图后到入口处按热键（默认 `Ctrl+Shift+F`，可在设置中修改）→ 状态行显示种子与置信度，投影自动出现。
- 地图开着时直接拖动/缩放，投影自动跟随；`G` 关地图投影同步隐藏。
- 认为种子不对：主窗「🔄 换种子」逐个试候选；楼层选错：「🔀 换楼层」。
- 「⋯ 更多」里是手动纠错入口与运行日志。

```bash
python eval/smoke_app_offscreen.py     # 离屏冒烟（UI/换种子/换楼层/接线）54/54

python eval/verify_entrance_e2e.py     # 入口+对齐端到端
python eval/e48_track_tick_live.py     # 跟踪主体真代码回归（改跟随必跑）
python eval/e33_follow_track.py        # 跟随·第二步（复刻版）10/10
python eval/e45_zoom_follow_replay.py  # 缩放跟随（复刻版）3/3
```

## 目录结构

```

core/                   匹配与对齐核心（vision / entrance / alignment / map_library）
ui/                     界面与系统层（capture / follow / track / overlay / hotkey / ...）
eval/                   回归测试 + 真值标注（labels.csv）+ 已入库回归脚本
assets/                 入口引索（entrance_index/）+ 图标/导航列模板
experiments/            一次性诊断脚本（gitignore，仅本机）
docs/                   计划文档
build_entrance_index.py 入口引索构建工具
build_ui_template.py    导航列模板构建工具
calib_annotate.py       校准标注图工具
```

## 已知限制

- 端到端真实通过率 **48%**（21/44，2026-09-18 基线）：瓶颈在入口层种子识别；错图集中在个别相似入口场景，其余为「拒答」而非「答错」。
- 多分辨率适配代码已就绪但未在真实非 1920×1080 上实测。
- 噩梦模式 3 楼层 + 地下室未做（架构已预留）。
- 窗口化运行的面板几何不可信，请全屏运行。
